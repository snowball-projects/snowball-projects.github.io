# Contributing

Discuss public direction, dependencies, project records, and substantive
editorial work before opening a pull request. Submit only publication-ready
material, preserve the static project-first structure, and run `npm run verify`.

Pull requests should explain the problem, the important decisions, and how the
result was verified. Final product direction and publication decisions remain
with snowball's founder.

provide it on those terms.
