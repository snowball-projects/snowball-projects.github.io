# Contributing

Discuss project records, public direction, new dependencies, and substantive
editorial work before opening a pull request. Do not submit working drafts.
Preserve the site's static, project-first structure and run the checks in
[README.md](README.md).

Pull requests should explain the problem, the important decisions, and how the
result was verified. Final product direction and publication decisions remain
with snowball's founder.
